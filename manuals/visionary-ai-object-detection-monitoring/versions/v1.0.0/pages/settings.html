Settings Overview & Backup

Use the Settings page to view or adjust configuration. Each settings group has a tab and an Edit icon that opens a side panel. Configure only one group at a time and reload when requested.

Settings tabs

Group Purpose
Camera Camera acquisition, color balance, auto exposure, depth validation, histogram equalization and optional advanced device SDK overrides. Details
Live streaming Preview capture rate, browser polling rate, output width and JPEG quality, freshness and request timeouts. Details
Object detection Inference cycle and non-maximum suppression (NMS) options. Details
MQTT client External broker connection and optional publication of detection results. Details
Logging Log verbosity, maximum entries and file-size setting. Details
Image collection settings Interval and max images are configured from the Image Collection start panel instead of having their own Settings tab.

Changing a setting

  1. Open Settings from the application menu.
  2. Select the relevant tab (Camera, Live streaming, Object detection, MQTT client or Logging).
  3. Click the edit/pencil icon beside that group title to open the edit side panel.
  4. Change the required parameters and select Save. Read and resolve validation messages if present.
  5. If the header indicates a reload is required, choose ⋮ → Reload app, confirm and verify App ready returns.
When changes apply: Camera, live-preview, detection, MQTT, logging and model changes are persisted but generally take effect after reload. The image-collection interval/max-image parameters are applied immediately when saved. Do not reload the camera during an active process without coordination.

Export and import settings

At the top of Settings you can Export settings to a JSON backup or choose a JSON file and click Import settings. Import prompts for confirmation, applies valid configuration, then offers Reload app.

  1. Before changes, use Export settings to create a rollback copy of the current configuration.
  2. Ensure all referenced model files already exist on the camera under their expected model IDs. A backup contains model configuration, not the model JSON file bytes.
  3. Choose a compatible backup in the file selector, click Import settings and confirm.
  4. Wait for the success message; if the import fails, read the error and correct the prerequisite rather than repeatedly restarting.
  5. Click Reload app and check the model list and Monitoring page. Export a new snapshot once commissioned.

Backup limits and safe handling

The settings JSON contains configuration values, runtime limits, model definitions and potentially saved MQTT credentials. It does not contain full trained model binaries or captured dataset images. Keep backups in an access-controlled location. The imported backup does not override the device’s existing saved stop/resume monitoring preference. Import is rejected during a running timed image-collection session and a persistence failure is rolled back.
