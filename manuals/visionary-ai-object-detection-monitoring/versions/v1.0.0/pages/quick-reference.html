Quick Reference

A concise operator and commissioning checklist for Visionary AI Object Detection Monitoring v1.0.0.

Before operation

  • Camera powered and reachable from the operator PC.
  • Deep Learning Classification license 1614850 activated on the camera, or verified suitable trial only for testing.
  • Compatible network model JSON installed and configured.
  • Settings optimized for the scene; pending changes reloaded.
  • Monitoring shows App ready and Camera connected, with correct live preview.

Daily tasks

Task Where and how
See live detections Monitoring → inspect box labels, confidences and live quantity panel.
Hide unnecessary overlays Monitoring → uncheck the model or class (display-only change).
Stop/resume monitoring Monitoring → Stop camera and detection / Resume; preference survives restart.
Change models Network Models → Add/Edit/Enable/Download; reload to apply.
Capture images Image Collection → Capture or Start collection → select images → Download selected.
Inspect failures Log Monitoring → filter Error/Warning; record time and message.
Edit system settings Settings → choose tab → Edit → Save → Reload when requested.
Configure external reporting MQTT client → broker credentials, topic, enable, save, reload; or use REST.
Activate inference license SICK LicenseManager → online or offline activation wizard.
