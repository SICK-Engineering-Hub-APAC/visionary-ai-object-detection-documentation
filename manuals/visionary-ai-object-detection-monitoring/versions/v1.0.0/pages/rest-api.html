REST API Reference

Service and application engineers can use the device’s Crown REST API to read status, retrieve settings, update configuration, operate models and obtain captured images. This reference is derived from the provided v1.0.0 OpenAPI specification and application source.

↓ Download complete OpenAPI v1.0.0 (YAML)

Connection & request format

Topic Details
Base URL http://<camera-ip>/api/crown (substitute device IP, scheme and port).
Function endpoint POST /api/crown/AIObjectDetectionMonitoring/{function}.
Request content type Content-Type: application/json. No-parameter functions accept {}.
Function arguments For functions with parameters, pass a data object such as {"data":{"enabled":false}}.
Response envelope {"header":{"status":0,"message":"Ok"},"data":{"data":"…","success":true,"message":"OK"}}.
Nested JSON string The inner data.data field often contains another JSON document as a string, requiring one more JSON parse.
Failure handling Check both header.status and data.success. App-level errors may still return HTTP 200; read data.message.
Credentials/security Use the authentication and network access controls configured on the target device; do not expose the API or camera to untrusted networks.

Examples for service engineers

Check application status

Replace CAMERA_IP with your camera address; send the no-parameter empty JSON object. 

curl -s -X POST "http://CAMERA_IP/api/crown/AIObjectDetectionMonitoring/getStatus" \
  -H "Content-Type: application/json" -d '{}'

When the response succeeds, decode the nested data.data string to inspect ready, cameraConnected, monitoringEnabled, workers, license state and reloadRequired.

Stop monitoring

curl -s -X POST "http://CAMERA_IP/api/crown/AIObjectDetectionMonitoring/setMonitoringEnabled" \
  -H "Content-Type: application/json" \
  -d '{"data":{"enabled":false}}'

This saves the disabled preference and stops monitoring. To resume, set enabled to true, then invoke reloadApps because enabling does not immediately restart inference from the API alone.

Change image collection options (partial settings update)

curl -s -X POST "http://CAMERA_IP/api/crown/AIObjectDetectionMonitoring/updateSettings" \
  -H "Content-Type: application/json" \
  -d '{"data":{"dataJSON":"{\"imageCollection\":{\"intervalMs\":2000,\"maxImages\":20}}"}}'

For example, image-collection interval and maximum images apply immediately after a successful save. Changing camera/detection/model/MQTT/logging settings requires a reload.

Read and parse the nested response in Python

import json
import urllib.request

url = "http://CAMERA_IP/api/crown/AIObjectDetectionMonitoring/getStatus"
req = urllib.request.Request(url, data=b"{}",
                             headers={"Content-Type": "application/json"},
                             method="POST")
with urllib.request.urlopen(req, timeout=10) as response:
    envelope = json.load(response)

if envelope.get("header", {}).get("status") != 0:
    raise RuntimeError(envelope.get("header"))
result = envelope.get("data", {})
if not result.get("success"):
    raise RuntimeError(result.get("message"))
status = json.loads(result["data"])
print(status["ready"], status["cameraConnected"], status["monitoringEnabled"])

Every function below uses POST under the common /api/crown/AIObjectDetectionMonitoring/ prefix.

Special parameter formats

Item How it works
dataJSON For updateSettings, importSettings, updateNetworkModel and updateNetworkModelFile, pass JSON-serialized text as a string value. Do not pass an unquoted object.
content Model uploads/replacements use the Crown binary object {"type":"binary","encoding":"base64","data":"..."} with base64 file bytes.
namesJSON For deleting or creating a ZIP from selected collected images, pass a JSON array of filenames encoded as a string.
getLiveFrame Returns a base64 binary image envelope; decode binary data before displaying a JPEG preview.
getCollectionImages Returns image records including device paths; download a returned file path with the file endpoint.
prepareDatasetDownload Produces a temporary archive path; download using GET /api/crown/file?filePath=<encoded-path>, then call acknowledgeDatasetDownload for cleanup.
reloadApps Reloads device apps to apply pending configuration changes; calls may be temporarily unavailable during the restart.

Image download using the path returned by the API

# Replace the placeholder with the EXACT path returned by the camera.
curl -G "http://CAMERA_IP/api/crown/file" \
  --data-urlencode "filePath=/REPLACE/WITH/RETURNED/PATH/image.png" \
  -o image.png

Real-time notifications

REST does not stream events. The device Crown WebSocket uses /crownJSON or /crownMSGPACK. Through the Crown protocol, register AIObjectDetectionMonitoring/onDetection, /onStatus, /onLog or /onCollection. Each event contains an argument data encoded as a JSON string. Use the compatible Crown SDK/client; a raw WebSocket subscription is not equivalent to a Crown event registration.

For a full machine-readable contract: Open the downloaded openapi.yaml in Swagger Editor or another OpenAPI viewer. It includes request schemas, validation bounds, sample payloads, response structures and event definitions.
