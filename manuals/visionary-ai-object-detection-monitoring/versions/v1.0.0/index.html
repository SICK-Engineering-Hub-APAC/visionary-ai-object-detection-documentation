Visionary AI Object Detection Monitoring

Operate, configure and monitor object detection directly on the SICK Visionary B-Two camera — with practical guidance for operators, service engineers and application engineers.

On-camera application2D object detectionVisionary B-Two

What the application does

The camera captures the live scene, runs an enabled deep-learning object-detection network model, and shows the identified object classes, confidence percentages, bounding boxes and current visible quantities in the browser. Optional MQTT and Crown WebSocket outputs make the results available to other systems.

Daily monitoring

See the live image, detection boxes, current object quantities and camera status. Stop or resume camera monitoring when required.

Getting started

  1. Confirm the Visionary B-Two camera is reachable over the network and this AppSpace application is installed and running.
  2. Confirm the required Deep Learning Classification license (SICK part number 1614850) is activated. Inference without a full device license can be 120-minute time limited and subsequently blocked.
  3. Open the camera in a browser, for example http://<camera-ip>/#/monitoring?msdd=AIObjectDetectionMonitoring.msdd. Replace the example IP with the actual camera address. Use the application navigation menu to switch pages.
  4. Obtain the compatible people-detection network model JSON separately from SICK and add it from Network models before enabling it.
  5. Check Settings, configure the required model and select Reload app from the header menu after changes; verify Camera connected and App ready.
  6. Open Monitoring; confirm the live scene and object boxes match expectations. Keep the scene and camera position stable for reliable results.
License required: SICK Deep Learning Classification license, part number 1614850.
